## 核心内容

### 概念与原理

**指令集架构（Instruction Set Architecture, ISA）**是软件与硬件之间的**契约**：定义了寄存器数量与宽度、寻址模式、指令格式与语义、内存模型与 ABI（Application Binary Interface）规则。程序员看到的是 ISA，微架构（microarchitecture）是具体实现（见后续流水线、乱序等）。

主流 ISA 分为：
- **复杂指令集 CISC（x86）**：变长指令、丰富的寻址模式，常支持内存操作数（如 `add [mem], reg`）。见[[01-07 CISC哲学与x86演进]]。
- **精简指令集 RISC（MIPS、ARM、RISC-V）**：定长指令、装载-存储（load/store）架构——只有 load/store 访问内存，运算只在寄存器间进行。见[[01-08 RISC哲学与ARM]]。

### 技术细节

#### 典型指令格式（RISC-V RV32I 基数指令集）
| 类型 | 字段 | 用途 |
|------|------|------|
| R | funct7 | rs2 | rs1 | funct3 | rd | opcode | 寄存器运算 |
| I | imm[11:0] | rs1 | funct3 | rd | opcode | 立即数运算/Load |
| S | imm[11:5] | rs2 | rs1 | funct3 | imm[4:0] | opcode | Store |
| B | 分支立即数混合 | rs2 | rs1 | funct3 | 分支 hi | opcode | 条件分支 |
| U | imm[31:12] | rd | opcode | | | `lui`/`auipc` |
| J | jal 立即数混合 | rd | opcode | | | `jal` |

字段位置固定是 RISC 的关键：译码与数据通路可并行提取立即数与寄存器号，利于流水线。

#### 寻址模式对比
- RISC-V：立即数加基址（对 load/store）、PC 相对分支与 `auipc`、绝对（`lui` 组合）。
- x86：寄存器间接、基址+变址+位移、SIB 编码等更丰富。

#### ABI 与调用约定
函数调用时参数传递与栈使用规则属于 ABI 一部分。RISC-V 规定 `a0-a7` 传参、`x1(ra)` 返回地址、`sp` 栈指针。编译器必须遵循，否则与库互操作失败（也是逆向中参数还原（见模块12对应篇）的依据）。

### 代码/命令示例

用 GCC 生成 RISC-V 汇编对照指令格式（rv64 工具链可选）：

```bash
riscv64-linux-gnu-gcc -march=rv64gc -S test.c -o - | head -30
# 观察 addi/add/beq 等指令隐含的寄存器编码
```

若本机无 RISC-V 工具链，可用 x86-64 的 objdump 观察类似模式：
```bash
gcc -O2 -S -c demo.c -o - | sed -n '1,40p'
```

## 实战案例（不少于全文30%篇幅）

### 案例1：比较 x86-64 与 RISC-V 的同一函数
- 场景描述：编译同一 `add(a,b)` 到两种 ISA，观察指令长度与内存操作的差异。
- 环境准备：Linux (x86-64) + gcc + riscv 工具链（或在线 Godbolt：https://godbolt.org）
- 操作步骤：
  1. 写 `int f(int a,int b){return a+b;}`
  2. x86: `gcc -O2 -S` → 观察 `lea` 或 `add`
  3. RISC-V: Godbolt 选择 rv64gc → 观察 `addw` 两条寄存器指令
- 预期结果：RISC-V 为定长 R 型；x86 常出现可变长与内存/寄存器混合。
- 关键分析：装载-存储架构的指令更规整，硬件译码简单，但指令数通常更多；CISC 指令数少但译码复杂——这是[[01-07]]、[[01-08]]哲学冲突的源头。

### 案例2：反汇编观察 ABI 传参
- 场景描述：反汇编一个无优化纯函数，识别 a0-a7 / x86 的 rdi-rsi 传参约定。
- 环境准备：Linux + objdump
- 操作步骤：
  1. 编译 `int f(int a,int b,int c){return a+b+c;}` 不优化。
  2. `objdump -d` 查看入口与参数使用的寄存器。
- 预期结果：参数按 ABI 顺序放入约定寄存器，无栈传参（除非参数过多）。
- 关键分析：ABI 逆向识别是分析未知二进制的基础（对应模块12 逆向篇的参数还原）。

## 常见误区与陷阱
1. 混淆 ISA 与微架构：ISA 是契约，流水线/乱序是实现。
2. 误以为 CISC 一定慢于 RISC：现代 x86 用微操作解码弥合差异。
3. 忽略 ABI：调用约定影响编译器、调试与逆向。
4. 认为 RISC-V 只有 32/64 位：存在 E 扩展（31 个寄存器）等变体。
