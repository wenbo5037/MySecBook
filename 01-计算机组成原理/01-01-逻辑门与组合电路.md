## 核心内容

### 概念与原理

组合电路（combinational circuit）的**输出仅取决于当前输入**，没有存储与反馈。与之相对的是时序电路（见[[01-02] 时序电路与触发器]]）。布尔代数由 George Boole 在 1854 年提出（《An Investigation of the Laws of Thought》），Claude Shannon 于 1938 年在论文《A Symbolic Analysis of Relay and Switching Circuits》中首次将布尔代数用于开关电路设计，奠定了数字电路的基础。

基本逻辑门与真值表（A、B 为 1 位输入）：

| 门 | 符号 | 真值表 (AB→Y) | 等价表达 |
|----|------|--------------|----------|
| 与 AND | `A·B` | 00→0 01→0 11→1 | Y = A·B |
| 或 OR | `A+B` | 00→0 01→1 11→1 | Y = A+B |
| 非 NOT | `¬A` | 0→1 1→0 | Y = A' |
| 异或 XOR | `A⊕B` | 00→0 01→1 11→0 | Y = A'B + AB' |
| 与非 NAND | `A↑B` | 全 1 时 0 | Y = (A·B)' |
| 或非 NOR | `A↓B` | 全 0 时 1 | Y = (A+B)' |

任何逻辑函数都可用与非门（或或非门）完全实现——这称为逻辑门的**功能完备性**，也是芯片制造只用一种标准单元的重要原因。

### 技术细节

#### 布尔代数三大定律

- 交换律、结合律、分配律：与普通代数相同
- 德摩根定律（De Morgan）：`(A·B)' = A' + B'`，`(A+B)' = A' · B'`
- 幂等律与吸收律：`A·A=A`，`A+A' = 1`

#### 卡诺图化简

卡诺图（Karnaugh map，1953 年 Maurice Karnaugh 提出）把真值表重排为格雷码序的方格矩阵，相邻格合并可消去变量。4 变量卡诺图中相邻的 2、4、8 格合并分别消去 1、2、3 个变量。

#### 典型组合电路

- **半加器**：仅处理两位相加，输出和 S = A⊕B、进位 C = A·B，不接收低位进位。
- **全加器**：增加进位输入端 Cin，S = A⊕B⊕Cin，Cout = A·B ⊕ Cin·(A⊕B)。N 个全加器级联构成 N 位行波进位加法器。
- **编码器/解码器**：m 位输入 → n 位二进制编码（如 8-3 编码器）。
- **多路选择器 MUX**：n 位选择信号从 2^n 个输入中选一输出。ALU 的操作选择即依赖 MUX。

### 代码/命令示例

用 Python 验证 1 位全加器逻辑（Python 3.11+）：

```python
def full_adder(a, b, cin):
    s = a ^ b ^ cin
    cout = (a & b) | (cin & (a ^ b))
    return s, cout

print(full_adder(1, 1, 1))   # (1, 1) → 1+1+1 = 3 (二进制 11)
print(full_adder(0, 1, 1))   # (0, 1) → 0+1+1 = 2 (二进制 10)
```

## 实战案例（不少于全文30%篇幅）

### 案例1：用 Logisim 搭建 2 位二进制加法器
- 场景描述：在图形仿真工具中设计并验证一个 2 位全加器，理解进制与电路映射。
- 环境准备：Logisim-evolution 2.7.x（任何 OS）
- 操作步骤：
  1. 新建工程，添加 4 个输入引脚（A1 A0 B1 B0）与 3 个输出（S0 S1 C2）。
  2. 用两个全加器级联：低位全加器 C1 接高位全加器 Cin。
  3. 连接 XOR、AND、OR 门（每级 3 个门）并按式子 S、Cout 布线。
  4. 拨动输入组合 10+01、11+11，观察输出。
- 预期结果：`11+11 = 110`（即 3+3=6），输出 S1S0C2 = 0 1 1 与手算一致。
- 关键分析：行波进位加法器延迟随位数线性增长，这是后续流水线（见[[01-10]]）乃至超前进位加法器改进的动力。

### 案例2：用 Python 验证卡诺图化简后的等价性
- 场景描述：对同一逻辑函数用表达式展开与真值表验证，确认化简不改变功能。
- 环境准备：Python 3.11+
- 操作步骤：
  1. 用真值表生成函数 F = A'B + AB'（=A⊕B）。
  2. 用 itertools 穷举全部 2^2 输入，比较 `F` 与化简式 `(A|B) & ~(A&B)`。
- 预期结果：两者在全部输入下输出一致。
- 关键分析：卡诺图化简只消去冗余项、不改变功能；自动化验证（穷举/形式化）是芯片验证的基础思路。

## 常见误区与陷阱
1. 把“或”混同于“异或”：或门 11→1，异或门 11→0。
2. 忽略德摩根定律：取反时忘记将“与改或、或改与”。
3. 卡诺图相邻格判断错误：第一列与最后一列也相邻。
4. 行波进位加法器延迟估错：最坏延迟与位数成正比，而非常数。
