## 核心内容

### 概念与原理

浮点数是离散的，任何实数都需要**舍入**到最近的可表示值。误差由**ULP（unit in the last place）**衡量，即当前邻域内两个可表示值之差。默认舍入模式 round-to-nearest ties-to-even（最接近偶数）保证对半情形选偶数尾数，避免统计偏好。

**陷阱类别**：
- **表示误差**：0.1 不精确。
- **大数吃小数（absorption/annex）**：大数与微小值相加结果不变。
- **相消（catastrophic cancellation）**：近似相等的两数相减损失有效位。
- **非结合性**：`(a+b)+c ≠ a+(b+c)`，因每次都舍入。

### 技术细节

#### ULP 与相对误差
相邻可表示数间距 = ULP。相对误差上界约 0.5 ULP ~ eps/2（eps=2^-52 双精度，2^-23 单精度）。

#### 相消详解
`1e16 + 1 - 1e16 = 0`（双精度下 1 被舍入掉），而准确结果应为 1。C 语言判断相等为 False 即误判。相对误差巨大即便绝对误差小。

#### 求和稳定性
**Kahan 求和**维护补偿项 `c` 累积丢失的低位，显著降低 O(N) 累积误差，接近精确和的误差界。

### 代码/命令示例

Python 演示三类陷阱与 Kahan 修复：

```python
# 吸收
print(1e16 + 1 == 1e16)          # True  → 小数被吃掉
# 非结合
print((0.1+0.2)+0.3 != 0.1+(0.2+0.3))  # True
# 相消
x = 1e16; print((x+1)-x)         # 0.0

def kahan_sum(xs):
    s = c = 0.0
    for x in xs:
        y = x - c; t = s + y
        c = (t - s) - y; s = t
    return s

print(kahan_sum([1e16, 1, -1e16]))  # 1.0
```

## 实战案例（不少于全文30%篇幅）

### 案例1：有限差分一步相消损失
- 场景描述：计算 `f(x+h)-f(x)`，x 很大 h 小时结果严重失真。
- 环境准备：Python 3.11+
- 操作步骤：
  1. 令 `a=1e16, b=1e16-2, a-b` → 2（仍精确，因可表示）。
  2. `c=1e16-1`：`a-c` 结果是否为 1？验证表示步长。
- 预期结果：若 `a-c` 以单精度或相邻 ULP 为 2 输出 0 或 2 而非 1。
- 关键分析：相消不是“减法本身错”，而是舍入后信息已不在；识别场景是数值安全前提。

### 案例2：Kahan 求和对大数据集
- 场景描述：对 10^6 个 1e8 量级均匀数与少量 1e-8 的差值流求和，对比朴素与 Kahan。
- 环境准备：Python 3.11+
- 操作步骤：
  1. 构造 `[1e8]*n + [1e-8]*n` 交错。
  2. 朴素 sum 与 kahan_sum 比较与高精度 decimal 参考值。
- 预期结果：Kahan 误差明显更低。
- 关键分析：掌握补偿算法是数值类工具（统计、图形）安全实现的通用技巧。

## 实验指南
1. 复现案例1、案例2。
2. 用 `Decimal` 或 `fractions` 构造参考精确值对比误差。
3. 选做：用 `-ffast-math` 观察编译对浮点重排后的非含律。

## 常见误区与陷阱
1. 用 `==` 比较浮点：应比较到容差（`math.isclose`）。
2. 相消与舍入混淆：一个是数据源无信息，一个是有信息但丢失。
3. 假设浮点结合律：优化器非 fast-math 下保持语义但可重排。
4. 用单精度存储双精度需求：UFP 差距按比例放大。
