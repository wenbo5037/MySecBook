## 核心内容

### 概念与原理

时序电路（sequential circuit）的**输出不仅取决于当前输入，还取决于历史状态**。这是因为它包含存储元件。组合电路（见[[01-01 逻辑门与组合电路]]）没有记忆能力；一旦引入反馈回路（把输出接回输入），就具备了记忆能力。两种基本存储单元：

- **锁存器 Latch**：电平触发（敏感电平），输入有效期间可多次翻转。
- **触发器 Flip-flop**：边沿触发（在时钟上升沿或下降沿采样一次），是同步时序电路的标准存储元件。

时序电路可用**状态机**描述：有限状态机（FSM）由状态集、输入集、转移函数和初始状态组成。时钟信号让所有触发器在同一时刻采样，从而保证系统同步与确定性。

### 技术细节

#### SR 锁存器（非门实现）

两个交叉耦合的与非门构成基本 SR 锁存器：S=1、R=1 为保持；S=0 置位 Q=1；R=0 复位 Q=0；S=R=0 为非法/不确定状态，应避免。

#### D 触发器

在时钟边沿把输入 D 锁存到 Q——输出的最终值和输入一样，且每周期只变化一次。是最常用触发器。特征方程：Q(t+1) = D。

#### JK 与 T 触发器

- JK：J=K=1 时**翻转**（消除 SR 的不确定态）。特征方程：Q(t+1) = J·Q' + K'·Q。
- T：T=1 每时钟翻转，T=0 保持，用于计数器分频。

#### 同步 vs 亚稳态

触发器在建立时间（setup）与保持时间（hold）窗口内输入变化会进入**亚稳态**（输出不定且振荡），这是跨时钟域同步（CDC）问题的根源，硬件安全（如熔丝、时钟毛刺）也常在时序上做文章。

### 代码/命令示例

用 Python 模拟 D 触发器与计数器的行为（Python 3.11+）：

```python
class DFlipFlop:
    def __init__(self):
        self.q = 0
    def posedge(self, d):     # 上升沿采样
        self.q = d

ff = DFlipFlop()
for i, d in enumerate([1, 1, 0, 1, 0]):
    ff.posedge(d)
    print(f"clk#{i+1} d={d} q={ff.q}")
```

输出 q 每周期跟随 d，体现边沿采样（时序与锁存不同）。

## 实战案例（不少于全文30%篇幅）

### 案例1：Logisim 级联 4 位二进制计数器

- 场景描述：用 T 触发器搭建 4 位二进制计数器（0→15），理解分频与状态依性。
- 环境准备：Logisim-evolution 2.7.x
- 操作步骤：
  1. 新建 4 个 T 触发器，每个 T=1 恒翻转。
  2. 前级 Q 接后级 CLK，形成异步（纹波）计数器。
  3. 加时钟源与 4 位显示，运行观察计数。
- 预期结果：每经一个时钟，计数值 +1；最高位频率为时钟的 1/16。
- 关键分析：从 T 触发器到计数器，展示“状态”如何在时序中累积，是寄存器（见[[01-03]]）与 CPU 内部状态机的基础。

### 案例2：观察亚稳态（实验思考）

- 场景描述：分析异步复位与输入竞争导致的亚稳态风险，体会时序安全。
- 环境准备：Logisim 或 Verilog 仿真（可选用 Icarus Verilog）
- 操作步骤：
  1. 构造 D 触发器，在建立时间窗口内改变 DMS（data & clock setup）。
  2. 在真实硬件上用两级同步器级联采样异步信号，比较采集稳定性。
- 预期结果：单级在竞争窗口内输出抖动；双级同步器显著降低亚稳态传播概率（MTBF 大幅提高）。
- 关键分析：亚稳态用\*\*MTBF（平均故障间隔）\*\*量化，硬件攻击方常利用时钟毛刺与定时攻击诱发非法状态，这正是芯片级侧信道与故障注入（见故障注入类）的物理基础。

## 常见误区与陷阱

1. 混淆锁存器与触发器：前者电平触发、后者边沿触发。
2. 认为 SR 的 S=R=0 是合法状态——它会导致 Q 与 Q' 同时为 1 的不确定态。
3. 忽略建立/保持时间，直接跨时钟采样导致亚稳态。
4. 把“状态”当作组合逻辑的一部分：状态必须显式存储。
