## 核心内容

### 概念与原理

IEEE 754（由 IEEE 发布，规范版本 754-2019）本质是科学计数法的二进制形式：`(-1)^S × M × 2^E`。单精度（binary32）32 位：符号 S 1 位、指数 E 8 位、尾数 M 23 位；双精度（binary64）64 位：S 1、E 11、M 52。

关键设计：
- **偏置指数（biased exponent）**：E 存储 `E_bias + 实际指数`。单精度 bias=127，双精度 bias=1023。
- **隐含 1（implicit leading 1）**：规格化尾数隐藏最高位 1，实际精度多 1 位（单精度 24 位有效位）。
- **特殊值**：全 0 指数+尾数=±0；全 0 指数非 0 尾数=**非规格化（subnormal）**；全 1 指数+全 0 尾数=±Inf；全 1 指数+非 0 尾数=NaN。

### 技术细节

#### 各布局
| 项 | binary32 | binary64 |
|----|----------|----------|
| 总位 | 32 | 64 |
| 指数 | 8 (bias127) | 11 (bias1023) |
| 有效位 | 23+1 | 52+1 |
| 最小正规格 | ~1.18e-38 | ~2.2e-308 |
| 最大 | ~3.4e38 | ~1.8e308 |

#### 换算示例
`9.75 = 1001.11b = 1.00111 × 2^3` ⇒ E=127+3=130，尾数存 00111000...。

#### 舍入规则
默认 **round-to-nearest ties-to-even（最接近偶数）**（见[[01-19]]浮点精度与舍入陷阱详述）。

#### 转换陷阱
- 整数→浮点：>2^24（单精度）时丢失低位精度。
- 判等陷阱：二进制小数（如 0.1）不能精确表示，`0.1+0.2 ！= 0.3`。

### 代码/命令示例

用 Python 查看位布局与精度丢失：

```python
import struct
f = struct.unpack('f', struct.pack('f', 9.75))[0]
bits = bin(struct.unpack('<I', struct.pack('f', f))[0])
print(bits)                      # 0b10000010000111...
print(16777216.0 == 16777217.0)  # True —— 单精度有效位限制
print(0.1 + 0.2 == 0.3)          # False —— 表示误差
```

## 实战案例（不少于全文30%篇幅）

### 案例1：手算 + 工具验证 9.75 的 binary32 编码
- 场景描述：据规则手算位串，再用 struct 验证。
- 环境准备：Python 3.11+
- 操作步骤：
  1. `9.75 = 1.00111 × 2^3`，指数=130 => `10000010`；尾数=`00111...0`。
  2. 组合 `0 10000010 00111000000000000000000`。
  3. 用前述 Python 打印对比。
- 预期结果：位串完全一致。
- 关键分析：把符号-指数-尾数映射成位流的技能几乎是逆向（如解析浮点数缓存）与编码正确性的基础。

### 案例2：单精度整数精度丢失演示
- 场景描述：找到最大的“奇数也可表示”的单精度整数，观察 2^24 后的步长。
- 环境准备：Python 3.11+
- 操作步骤：
  1. 对 `2**24` 起逐步 +1 转 float 再转回 int。
  2. 打印哪些整数会改变（用 `float(i)==float(i+1)` 判断）。
- 预期结果：2^24 之后每 2、4、8…个整数才可表示。
- 关键分析：认识到精度分级（UFP 步长随指数增长）正是浮点表示的代价，影响大整数统计类实现。

## 常见误区与陷阱
1. 把二进制小数当精确：绝大多数十进制小数不可精确表示。
2. 忽略偏置指数：实际指数比存储小 127/1023。
3. 忘记隐含 1：非规格化与 0 处理特殊。
4. 比较浮点用 `==`：需 eps/`math.isclose`。
