# 03-001 红队方法论与 ATT&CK 导航

## 基础信息
- 难度：中级
- 前置知识：[[01-001-二进制安全概览与学习路线]]
- 对应语言等级：熟悉级（C/C++），精通级（Python）

## 核心原理

红队（Red Team）是在客户明确授权范围内，以真实攻击者的行为模式检验组织防御有效性的安全测试形态，区别于常规渗透测试：红队模拟「有明确目标、能持续行动、讲究隐蔽」的对抗过程，而非单纯逐项验证漏洞。其方法论精髓是 **MTTC（时间成本）与 ITC（预算成本）约束下的"像对手一样思考"**——评估对象从「某个漏洞能不能打」升级为「整条攻击链能否落地、能否被发现」。

导航一切的框架是 **MITRE ATT&CK**（Adversarial Tactics, Techniques, and Common Knowledge）：以战术（Tactics，攻击者目标，如 Initial Access、Persistence、Privilege Escalation、Defense Evasion）为纵轴，以技术（Techniques，达成目标的具体手法，如 T1059 命令与脚本解释器、T1136 创建账号）为横轴。ATT&CK 同时给出检测建议（Detection）与缓解建议（Mitigation），使红队操作与蓝队检测能在同一张图谱上对表。

## 技术要点

- **ATT&CK 结构**：Tactic（战术）→ Technique/Sub-technique（技术/子技术，如 T1055 进程注入含 T1055.001 `DLL同步注入`）→ Procedure（具体操作）；每项技术有编号、ID、参考实例与平台适用范围。
- **红队执行流（Kill Chain 视角）**：
  1. 侦察（Reconnaissance）：被动（OSINT/泄露库）与主动（端口服务探测、Web 指纹）；
  2. 初始访问（Initial Access）：钓鱼、暴露服务利用、预置硬件/软件供应链；
  3. 执行/维持（Execution/Persistence）：计划任务、注册表 Run Key、服务化、DLL 劫持；
  4. 提权/凭据（Privilege Escalation/Credential Access）：内核/EoP 漏洞、LSASS 转储、Mimikatz 类凭据窃取；
  5. 防御规避/横向/渗出（Defense Evasion/Lateral Movement/Exfiltration）。
- **OPSEC（操作安全）**：日志清零、时间窗口控制、C2 通信伪装、内存中加载（fileless）、避免高危命令落地。红队的一切动作首先要回答"如何不被蓝队看见"。
- **任务授权边界**：Scope（目标 IP/域名/系统）、Rules of Engagement（可接受手段、时间窗口、可破坏性、应急停手条款）。越界即违法，授权文件是红队工作的第一道也是法律唯一一道屏障。

## 实践示例

环境：Kali Linux 2024.2、ATT&CK Navigator 4.x（本地部署）。

使用 ATT&CK Navigator 建立红队作战看板：把「目标阵营的性质」映射为战术矩阵，勾选本任务计划用到的技术并导出 JSON/Excel，作为行动前路线图：

```bash
# ATT&CK Navigator 是纯前端 Web 应用，直接访问 Github.io 或本地部署
git clone https://github.com/mitre-attack/attack-navigator.git
cd attack-navigator && npm install && npm run start
# 浏览器打开 http://localhost:4200
# Layer → New Layer → 选择 "Enterprise" 知识库
# 在矩阵中勾选：T1059（命令与脚本解释器）/ T1136（创建账号）/ T1098（账号操纵）等
```

用 ATT&CK 枚举一次模拟攻击链对应战术：初始访问 T1566（钓鱼）→ 执行 T1059.003（PowerShell）→ 持久化 T1547.001（注册表 Run Key）→ 提权 T1134（访问令牌操纵）。每项技术查 ATT&CK 页面的「Detection」「Mitigation」字段，直接复用为检测清单。

## 常见问题与误区

- 误区一：把渗透测试当红队。无授权范围内的临时处置、无持续隐蔽目标、无检测对抗，都不能叫红队；红队的关键词是"持续对抗与极限检验"。
- 误区二：堆技术而缺战术思维。攻击者依据目标选择技术，而非把技术清单依次打一遍；ATT&CK 是用来规划与叙述攻击链的，不是打分表。
- 误区三：忽视授权与合规边界。未授权的扫描即违法；务必坚持书面授权、明确规定动作清单与停手点，涉及攻击的整条链路都需落档留存。
